# ❤️ Heart Disease Prediction

## 📌 Objective
Build a Machine Learning model to predict the likelihood of heart disease based on patient health parameters.

## 🔍 Key Tasks
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature selection and correlation analysis
- Model training using classification algorithms
- Model evaluation and prediction

## 📊 Features Used
- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol
- Maximum Heart Rate
- Exercise Induced Angina
- Oldpeak
- ST Slope
- And more...

## 🛠 Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 🚀 Workflow
Raw Data → Cleaning → Feature Analysis → Model Training → Prediction

## 💡 Outcome
Built a predictive Machine Learning model to identify heart disease risk and understand important medical factors affecting diagnosis.
